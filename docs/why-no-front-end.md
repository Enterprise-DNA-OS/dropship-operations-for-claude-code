# The supplier desk without another app

The useful record is a set of suppliers, product snapshots, promises, shipments and return cases. The operator asks for a review and the coding agent runs the recorded commands. Branded HTML is a read-only result that can be opened or printed, not another business application to maintain.

A dedicated app supplies mobile capture, offline work, barcode scanning, drag-and-drop allocation, authenticated supplier access and live notifications. This base supplies none of those. Enterprise DNA can build the interfaces and connections the business needs. A public storefront remains a separate system.

The CLI holds the rules. AGENTS.md points every coding agent to the same command library. The database can be backed up and queried independently of the agent. Private database access, trusted operators and reviewed drafts remain necessary.
