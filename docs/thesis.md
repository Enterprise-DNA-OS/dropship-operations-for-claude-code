# Own the supplier record

Duoplane connects shops and suppliers and automates the work between them. The owned alternative starts with the operational records: what each supplier accepted, when it promised to ship, what has left and what still needs a response.

A database and a coding agent can run that desk without a new interface. Read-only documents and views give owners something concrete to review. Live connections and supplier access are implementation work for the business's version. The base never pretends an imported snapshot is a live feed.

Omni by Enterprise DNA builds and runs that version. The free software stays MIT licensed and the records stay with the owner.
